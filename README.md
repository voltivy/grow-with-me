# Grow With Me
Open index.html in a browser to play. Progress saves in that browser.

Files
- index.html        page structure
- css/style.css     all styling
- js/config.js      YOUR WORDS: names, sign, memories, letter
- js/core.js        data, saving, sound
- js/sprites.js     pixel art drawing and scenes
- js/game.js        gameplay, screens, main loop
- main.js, package.json   Electron wrapper (npm install, npm start, npm run build)
